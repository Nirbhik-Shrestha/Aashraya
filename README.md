## 🌟 About Aashraya

**Aashraya** (Sanskrit: आश्रय, meaning "shelter" or "refuge") is a comprehensive mental health and wellness platform designed to support individuals on their journey toward emotional well-being. Built with the MERN stack, it provides a safe, supportive, and anonymous environment for users to track their mental health, connect with others, and access crisis resources.

## ✨ Features

### 🔐 Authentication System
- **Secure Login/Register**: User authentication with form validation
- **Session Management**: Persistent user sessions
- **Protected Routes**: Secure access to personal features

### 😊 Mood Tracker
- **Daily Check-ins**: Log your emotional state with intuitive emoji interface
- **Mood Analytics**: Track patterns and trends over time
- **Visual Feedback**: Interactive mood selection with smooth animations

### 🫁 Breathing Exercises
- **Guided Breathing**: Animated breathing circle with 4-second cycles
- **Stress Relief**: Proven techniques for anxiety management
- **Mindfulness Practice**: Build daily meditation habits

### 💬 Anonymous Discussion Forum
- **Safe Space**: Completely anonymous community discussions
- **Peer Support**: Connect with others facing similar challenges
- **Privacy First**: No personal information required for participation

### 🔥 Streak System
- **Habit Tracking**: Gamified approach to building healthy routines
- **Visual Progress**: 14-day streak visualization
- **Daily Goals**: Customizable wellness activities checklist

### 🚨 Crisis Mode Support
- **Emergency Access**: One-click access to mental health resources
- **24/7 Availability**: Always accessible crisis hotlines
- **Professional Resources**: Vetted mental health emergency contacts

### 📚 Mental Health Resources
- **Educational Blogs**: Professional articles on mental wellness
- **FAQ Section**: Common questions about mental health
- **Resource Library**: Curated content from mental health professionals

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (v4.4 or higher)
- npm or yarn package manager

## 🛠️ Technology Stack

### Frontend
- **React 18**: Modern UI library with hooks
- **CSS3**: Custom styling with animations and responsive design
- **Font Awesome**: Icon library
- **Local Storage**: Client-side data persistence

### Backend (Recommended)
- **Node.js**: JavaScript runtime
- **Express.js**: Web application framework
- **MongoDB**: NoSQL database
- **Mongoose**: MongoDB object modeling
- **JWT**: Authentication tokens
- **bcryptjs**: Password hashing

### Development Tools
- **Prettier**: Code formatting
- **Nodemon**: Development server

## 🔒 Security Features

- **Password Hashing**: Secure password storage with bcryptjs
- **JWT Tokens**: Stateless authentication
- **Input Validation**: Client and server-side validation
- **CORS Protection**: Cross-origin request security
- **Anonymous Posts**: Privacy-first forum design

## 🎨 Design Philosophy

- **Calming Aesthetics**: Soothing color palette for mental wellness
- **Accessibility First**: WCAG compliant design
- **Intuitive UX**: User-centered design approach
- **Mobile First**: Responsive design for all devices
- **Performance Optimized**: Fast loading and smooth interactions
